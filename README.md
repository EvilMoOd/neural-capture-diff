# NC Device

Neural DSP capture 参数速览：按设备查看云端的全部 capture 快照，并以 **#1 快照为基准高亮参数差异**，方便对比同一设备在不同设置下的变化。

共收录 169 台设备：官方清单 164 台，分布在 7 个官方分类中（Guitar amps、Bass amps、Bass overdrive、Guitar overdrive、Guitar combo amps、Compressor、Fuzz pedals），另有 5 台官方清单之外的设备归入「未收录设备」。其中 158 台包含可解析的参数快照（共 2036 个快照），其余设备在云端只有 `Settings: N/A` 或缺失描述的 capture。Capture V2（版本 3.3.0）设备会在标题旁显示 `V2` 标签。

## 怎么用

- **选择设备**：左侧列表按类别分组；手机端点击顶部「☰ 设备列表」打开抽屉。
- **查看差异**：表格纵轴是快照，横轴是参数。与基准快照不同的值会高亮，`—` 表示该快照没有这个参数。默认以 #1 为基准，点击任意快照编号即可切换；若没有 #1 快照，则以第一个快照为基准。
- **搜索**：列表顶部输入设备名即可过滤。
- **常用置顶**：点击设备右侧的 `☆` 置顶，`★` 取消；置顶记录只保存在当前浏览器。
- **滚动**：表头和首列会固定，横向滑动查看全部参数。
- **表格全屏**：点击表格右上角「⛶ 表格全屏」让表格占满屏幕；手机横屏等高度较小的窗口会自动进入全屏，点击「✕ 退出全屏」或按 `Esc` 退出。
- **侧边栏**：桌面端点击标题旁的 `«` 收起，收起后点「☰ 展开菜单」恢复。
- 页面自动跟随系统的深色 / 浅色模式。

## 关于数据

- 参数整理自 Neural DSP Cloud 上公开的 capture 信息，仅用于对比与学习参考。
- 设备分类和「基于 / Based on」以官方设备清单为准；清单之外的设备归入「未收录设备」。
- 云端将同一台设备拆分成多个 capture 名称时（如 Tech41 BDDI、Tech41 PSA、Mad Pro、Bogna X、CA MixBass 的多个变体），已合并为同一台设备展示，实际采样名称会列在右侧表格中。
- 官方清单名称与云端原始 capture 名称不一致时（如 `Brit 2203 87` 对应 `Brit 1987`），右侧表格会同时标出原始采样名称；仅大小写或撇号差异的 `CA John's` 系列不额外展示。
- 描述为空的 capture 会保留在对应设备中，参数留空；与已有快照编号重复的空描述上传视为重复项，不予重复展示。
- 部分设备的 capture 描述为 `Settings: N/A` 或缺失，无法生成参数表，仅保留设备名称与说明（列表中标为「无参数」）。
- 快照名称和编号以原始 capture 为准，编号可能不连续。
