# NC Device

Neural DSP capture 参数速览：按设备查看云端的全部 capture 快照，并以 **#1 快照为基准高亮参数差异**，方便对比同一设备在不同设置下的变化。

当前收录 163 台设备、2036 个快照。

## 怎么用

- **选择设备**：左侧列表按类别分组；手机端点击顶部「☰ 设备列表」打开抽屉。
- **查看差异**：表格纵轴是快照，横轴是参数。与基准快照不同的值会高亮，`—` 表示该快照没有这个参数。默认以 #1 为基准，点击任意快照编号即可切换；若没有 #1 快照，则以第一个快照为基准。
- **搜索**：列表顶部输入设备名即可过滤。
- **常用置顶**：点击设备右侧的 `☆` 置顶，`★` 取消；置顶记录只保存在当前浏览器。
- **滚动**：表头和首列会固定，横向滑动查看全部参数。
- **侧边栏**：桌面端点击标题旁的 `«` 收起，收起后点「☰ 展开菜单」恢复。
- 页面自动跟随系统的深色 / 浅色模式。

## 关于数据

- 参数整理自 Neural DSP Cloud 上公开的 capture 信息，仅用于对比与学习参考。
- 设备分类和「基于 / Based on」为人工整理，可能存在偏差。
- 快照名称和编号以原始 capture 为准，编号可能不连续。
